# Skill — Bug Investigation

## Purpose

Diagnose before changing.

## Procedure

1. Reproduce or establish the reported failure.
2. Inspect logs/errors and relevant code.
3. Identify expected versus actual behavior.
4. Trace likely causal paths.
5. Form a falsifiable hypothesis.
6. Test the hypothesis.
7. Implement the smallest justified fix.
8. Add or update regression coverage.
9. Verify.
10. Report remaining uncertainty.

## Prohibited behavior

Do not patch symptoms without investigating the causal path.
