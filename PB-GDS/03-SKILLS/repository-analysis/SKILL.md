# Skill — Repository Analysis

## Purpose

Build a reliable model of an unfamiliar repository before changing it.

## Procedure

1. Identify repository and default branch.
2. Inspect root structure.
3. Read README and project instructions.
4. Inspect manifests and build configuration.
5. Inspect tests.
6. Inspect CI/workflow configuration.
7. Inspect relevant issues and pull requests.
8. Identify architecture boundaries.
9. Record uncertainties.
10. Produce a bounded change plan.

## Output

REPOSITORY
CURRENT STATE
ARCHITECTURE
RELEVANT RULES
RISKS
PLAN
VERIFICATION PLAN
