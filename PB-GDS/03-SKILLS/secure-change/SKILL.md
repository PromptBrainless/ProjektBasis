# Skill — Secure Change

## Purpose

Prevent security regressions during implementation and review.

## Procedure

1. Identify secrets and credential boundaries.
2. Inspect dependency changes.
3. Inspect CI permissions.
4. Inspect third-party actions.
5. Inspect external input boundaries.
6. Check security tooling.
7. Verify that sensitive values are not committed or exposed.
