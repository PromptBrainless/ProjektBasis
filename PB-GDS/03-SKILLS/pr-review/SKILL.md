# Skill — Pull Request Review

## Procedure

1. Establish base and head.
2. Read PR description and linked issue.
3. Inspect changed files and diff.
4. Inspect relevant history.
5. Evaluate correctness and regression risk.
6. Evaluate tests.
7. Evaluate security.
8. Classify findings by severity.
9. Report actionable findings.
10. Distinguish defects from preferences.
