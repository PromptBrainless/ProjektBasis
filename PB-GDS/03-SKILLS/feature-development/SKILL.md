# Skill — Feature Development

## Purpose

Implement a bounded feature while preserving repository integrity.

## Procedure

1. Read project instructions.
2. Inspect architecture and existing behavior.
3. Identify issue/request scope.
4. Establish branch.
5. Plan smallest coherent change.
6. Implement.
7. Run relevant tests/type checks/build.
8. Inspect diff.
9. Review security and regression risks.
10. Prepare PR/release notes when appropriate.

## Required output

SCOPE
FILES CHANGED
TESTS
RISKS
FOLLOW-UP
