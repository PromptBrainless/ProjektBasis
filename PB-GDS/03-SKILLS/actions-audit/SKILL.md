# Skill — GitHub Actions Audit

## Procedure

1. Enumerate relevant workflows.
2. Inspect triggers.
3. Inspect permissions.
4. Inspect secrets.
5. Inspect third-party actions.
6. Inspect untrusted input.
7. Inspect artifacts and deployment.
8. Identify excessive privileges.
9. Propose least-privilege changes.
10. Verify workflow syntax/tests where possible.
