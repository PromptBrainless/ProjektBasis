# Skill — Change Review

## Purpose

Review a proposed change for correctness, regression risk, security and maintainability.

## Procedure

1. Establish base and head.
2. Inspect changed files.
3. Inspect diff.
4. Inspect commit history where relevant.
5. Compare change against issue/request.
6. Check tests and automation.
7. Check security-sensitive paths.
8. Classify findings by severity.
9. Distinguish defects from preferences.
10. Report actionable findings.
