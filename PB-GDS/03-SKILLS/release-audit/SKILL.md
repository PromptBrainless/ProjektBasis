# Skill — Release Audit

## Purpose

Verify that a release candidate is internally consistent and traceable.

## Procedure

1. Identify release source commit.
2. Inspect version metadata.
3. Inspect release notes/changelog.
4. Verify build.
5. Verify tests.
6. Inspect deployment workflow.
7. Check artifacts.
8. Confirm target environment.
9. Record evidence and gaps.

## Output

SOURCE
VERSION
BUILD
TESTS
ARTIFACTS
DEPLOYMENT
RISKS
EVIDENCE
