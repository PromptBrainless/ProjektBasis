# PB-GDS — PromptBrainless GitHub Development System

PB-GDS is a versioned knowledge, rules and skills system for reliable Git/GitHub-assisted software development.

## Architecture

SOURCE → KNOWLEDGE → RULES → SKILLS → ORCHESTRATOR

- SOURCE: authoritative documentation and learning resources
- KNOWLEDGE: normalized concepts and workflows
- RULES: numbered operational requirements
- SKILLS: task-specific agent procedures
- ORCHESTRATOR: master system instruction selecting the required skills

## Rule namespaces

- PB-GH: GitHub platform
- PB-GIT: Git
- PB-WF: development workflows
- PB-AI: AI-agent behavior
- PB-SEC: security
- PB-QA: testing and quality
- PB-REL: release/deployment

## Status

v0.1 Foundation. The system is intentionally built on a dedicated branch before integration into main.
