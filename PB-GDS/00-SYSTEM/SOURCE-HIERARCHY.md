# Source Hierarchy

## Priority

1. Current official Git documentation
2. Current official GitHub documentation
3. Official GitHub Skills
4. Official Microsoft Learn GitHub training
5. Repository-local documentation
6. Established project conventions
7. Community practice
8. Agent inference

## Source rule

A source may establish a fact. An operational rule is an explicit PB-GDS derivation and must not be disguised as an official platform statement.

## Required source record

Each source note records:
- source ID
- canonical URL
- title
- retrieved/checked date
- scope
- concepts extracted
- operational rules derived
- unresolved ambiguity
- related PB-GDS IDs
