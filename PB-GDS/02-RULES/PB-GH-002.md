# PB-GH-002 — Plan before non-trivial implementation

- type: WORKFLOW
- source: PB-GDS-SRC-001

## Principle

GitHub's introductory workflow places work planning before local implementation.

## Agent behavior

For non-trivial changes:
1. identify the requested outcome
2. inspect the repository
3. identify relevant issue/project context when available
4. define a bounded change
5. implement
6. review and verify

## Exception

Tiny, self-contained documentation or metadata edits may not require an issue.
