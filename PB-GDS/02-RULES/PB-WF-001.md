# PB-WF-001 — Use a bounded change lifecycle

- type: WORKFLOW
- source: PB-GDS-SRC-005

## Lifecycle

UNDERSTAND → INSPECT → PLAN → BRANCH → IMPLEMENT → TEST → REVIEW → INTEGRATE

## Agent behavior

Select only the stages relevant to the requested change, but do not skip inspection, verification or review merely for speed on non-trivial changes.
