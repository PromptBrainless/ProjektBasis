# PB-GH-003 — Repository instructions are executable context

- type: OPERATIONAL
- source: PB-GDS-SRC-001

## Principle

Repository-local documentation can define project-specific development constraints.

## Agent behavior

Before non-trivial changes, inspect applicable:
- README
- CONTRIBUTING
- AGENTS.md
- Copilot instructions
- SECURITY.md
- CODEOWNERS
- package manifests
- workflow files

## Verification

Record which repository rules were relevant to the task.
