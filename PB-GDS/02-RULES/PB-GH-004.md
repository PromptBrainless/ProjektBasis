# PB-GH-004 — Use branches as collaboration boundaries

- type: WORKFLOW
- source: PB-GDS-SRC-005

## Principle

GitHub Flow is branch-based.

## Agent behavior

For non-trivial collaborative work, create or use a dedicated branch unless repository policy explicitly dictates another workflow.

Keep the branch scope coherent and reviewable.

## Exception

Tiny isolated edits may be performed without a dedicated feature branch when project policy allows it.
