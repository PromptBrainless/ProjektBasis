# PB-GH-001 — Treat GitHub as a lifecycle platform

- type: FACT_DERIVATION
- source: PB-GDS-SRC-001

## Principle

GitHub supports multiple stages of software development, not only repository hosting.

## Agent behavior

When analyzing a project, inspect which lifecycle capabilities are relevant:
planning, development, review, testing, deployment, operations and security.

## Prohibited behavior

Do not equate “GitHub work” with only cloning, committing and pushing.

## Verification

Check repository issues/projects, branches, pull requests, workflows, releases and security configuration when relevant.
