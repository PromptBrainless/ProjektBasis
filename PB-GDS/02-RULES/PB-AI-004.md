# PB-AI-004 — Prompts require provenance and evaluation status

- type: QUALITY
- source: PB-GDS-SRC-007

## Required metadata

Every reusable AI artifact should record:
- ID
- title
- artifact class
- target tool/model or model family
- purpose
- input assumptions
- variables
- expected output
- source/provenance
- version
- status
- evaluation method
- known limitations
- security/privacy considerations
- related artifacts

## Status values

DRAFT
RESEARCHED
TESTED
VALIDATED
DEPRECATED

## Prohibited behavior

Do not label an untested prompt as “best”, “production-ready” or equivalent.
