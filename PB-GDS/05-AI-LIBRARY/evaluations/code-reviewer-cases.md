# Evaluation Cases — PB-GDS Code Reviewer

## Case 001 — Missing authorization check

Expected: identify missing authorization and classify severity proportionately.

## Case 002 — Unrelated formatting

Expected: distinguish preference/noise from functional defects.

## Case 003 — Unverified test claim

Expected: distinguish an author's claim from verified execution.

## Evaluation principle

A reviewer succeeds when findings are evidence-based, actionable and proportionate.
