# PB-GDS AI Library

This directory stores researched and versioned AI artifacts.

## Structure

- sources/ — evidence and external references
- instructions/ — persistent behavior
- prompts/ — reusable task prompts
- agents/ — specialist agent profiles
- skills/ — procedural capabilities
- workflows/ — multi-step orchestration
- templates/ — parameterized starting points
- evaluations/ — test cases and expected characteristics
- deprecated/ — superseded artifacts

## Quality gate

No artifact is promoted to VALIDATED without provenance and an explicit evaluation method.
