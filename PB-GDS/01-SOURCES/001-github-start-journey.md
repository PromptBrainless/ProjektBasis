## Extracted structure

GitHub's introductory journey is organized as:
1. What is GitHub?
2. Create a repository
3. Plan work
4. Connect locally
5. Write and save code
6. Review proposed changes
7. Automated deployment
8. Git and GitHub learning resources

## Operational interpretation

The sequence demonstrates a lifecycle rather than a requirement that every project must use every feature.

The system should therefore distinguish:
- planning state
- source state
- collaboration/review state
- automation/deployment state
