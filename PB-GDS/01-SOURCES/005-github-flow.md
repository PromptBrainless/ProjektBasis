# Source 005 — GitHub Flow

Canonical source:
https://docs.github.com/de/get-started/using-github/github-flow

## Extracted principle

GitHub Flow is a lightweight, branch-based workflow for collaboration.

## Operational consequence

For ordinary feature work, PB-GDS prefers an explicit branch → change → review → integration lifecycle.

This is a default workflow, not an unconditional rule for every repository or every change.
