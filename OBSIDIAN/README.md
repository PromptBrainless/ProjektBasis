# PB Knowledge Vault — Obsidian

Versioned knowledge-system seed for the PromptBrainless ecosystem.

## Architecture

GitHub is the canonical operational source for code, executable agent configuration, skills, workflows, releases and project history.

Obsidian is the knowledge layer for concepts, research, decisions, relationships, prompt engineering, evaluations and project context.

```
Source → Research → Knowledge Note → Verified Pattern → PB-GDS Artifact → Evaluation → Revision
```

## Canonical boundary

Do not make Obsidian the second source of truth for executable project configuration. Link to the canonical GitHub artifact instead.

## Status model

DRAFT → RESEARCHED → TESTED → VALIDATED → DEPRECATED

A note must not be marked VALIDATED without explicit evidence and an evaluation method.
